第 1 章 系统概述

1.1 平台简介

开平市中心医院能源管理平台是一套覆盖全院 10 栋楼宇的能源与设备数字化管控系统。平台以「数字孪生大屏 + 运维管理后台」双端形态运行：大屏面向展示与监视，后台面向配置与管理。

全院 10 栋楼分别为：1 号楼（120 急救中心）、2 号楼（门诊大楼）、3 号楼（住院大楼）、4 号楼（妇产儿科大楼）、5 号楼（张襯大楼）、6 号楼（后勤楼）、7 号楼（药剂楼）、8 号楼（余锦炯大楼·放疗楼）、9 号楼（综合大楼）、10 号楼（宿舍楼）。每栋楼均配备以下七大子系统：

编号子系统名称英文标识
S1智慧能源一体化调控平台regulation
S2设备生命周期管理系统lifecycle
S3空调集中控制调度系统hvac
S4智慧照明管理系统lighting
S5医院电力监控系统power
S6热水集中控制调度系统hotwater
S7电梯节能管理系统elevator

1.2 系统组成

平台由两大部分组成，共用同一访问地址与同一套账号体系：

端入口主要用途
综合态势大屏/bigscreen/overview（打开首页即达）三维院区展示、楼栋/楼层浏览、七屏数据驾驶舱、告警与能耗总览
运维管理后台/admin楼栋/楼层/设备/告警/能耗等数据管理，大屏样式与布局 DIY，用户权限与审计

后台对数据的任何修改（如楼栋层数、设备台账、大屏布局）保存后，大屏端即时联动生效。

第 2 章 登录与访问

2.1 打开系统

步骤：

  1. 在电脑浏览器地址栏输入 http://117.21.178.39:5168；
  2. 页面打开后默认进入「综合态势大屏」（综合概览驾驶舱），如图 2-1 所示。

图 2-1　综合态势大屏首页（全院总览 + 三维院区）

2.2 账号与自动登录说明

本系统当前交付版本无独立登录页：应用启动时会以前端演示账号（admin / admin123）自动换取登录令牌（JWT），因此打开页面即处于已登录状态，可直接访问大屏与管理后台的所有页面。

账号与权限说明：

角色权限范围典型用途
admin（管理员）全部功能，含用户/角色管理、Schema 编辑器、审计配置系统管理员日常维护
运维/值班等业务角色按角色配置的功能权限（如设备、告警、能耗页面）日常运维值班
只读查看角色仅查看，无修改与导出权限参观展示、审计查阅

说明：若页面出现「接口请求失败」或菜单空白，多为后端服务未启动或网络不通，请确认服务器 5168 端口可达后刷新页面。

2.3 进入管理后台

两种方式任选其一：

  1. 在浏览器地址栏直接输入 http://117.21.178.39:5168/admin；
  2. 在大屏页左上角点击系统名称/返回入口切换至后台（后台页左下角有「返回态势大屏」按钮可切换回大屏）。

后台默认打开「楼栋子系统配置」页。顶部显示当前登录账号（admin）与「退出」按钮，左侧为功能菜单栏。

2.4 退出登录

在后台任意页面右上角点击「退出」按钮即可退出当前账号。退出后刷新页面会重新触发自动登录；如需更换账号，请先在「用户管理」中配置新账号并调整角色权限，或联系系统管理员。

第 3 章 综合态势大屏操作

3.1 大屏界面总览

综合态势大屏（图 3-1）自上而下分为四个区域：

  1. 顶部系统栏：左侧为医院名称与主题；中间为 7 个屏幕切换标签（图1–图7）；右侧为数据模式徽章与日期时间、天气。
  2. 楼栋导航条：10 个楼栋按钮横向排列，每个按钮显示「楼栋名 + 楼层数（如 12F）」，点击即选中该楼栋。
  3. 中央三维区：院区三维模型与地坪，支持鼠标拖转、缩放、点选楼栋；选中楼栋后左侧出现该楼楼层列表。
  4. 左右数据面板：S1–S7 七大子系统实时数据卡片，底部为「今日运行情况」汇总（设备总数、离线数、今日能耗、今日告警、工单处理）。

3.2 顶部七屏切换

点击顶部标签可在 7 个驾驶舱屏之间切换，各屏内容如下：

屏号名称主要内容
图1主驾驶舱全院总览：S1–S7 子系统卡片、楼栋导航、今日运行情况、三维院区
图2空调与能源冷机—冷却塔—水泵—末端链路、分区温度、能效分析、能耗占比与排名
图3电梯安全电梯编号表、运行统计、故障告警、实时位置（井道行程）、维保计划
图4供配电计量配电总览（10kV 进线与变压器）、变压器负载、馈线状态、电能质量

提示：在图1 主驾驶舱中点击 S1–S7 卡片可下钻至对应子系统屏（联动切屏），与顶部标签等效。

3.3 楼栋导航与楼层列表

楼栋与楼层是大屏的核心操作主线：

  1. 选楼：点击顶部楼栋导航条中的任一楼栋（如「4 号楼」），该楼栋高亮，三维镜头自动飞行至该楼栋，右侧面板切换为该楼栋的子系统数据（如 S7 电梯节能运行·4 号楼）。
  2. 看楼层：选中楼栋后，画面左侧出现楼层列表面板，自下而上排列该楼全部楼层按钮（F1、F2 … FN），面板头部显示楼栋名称与总层数，如图 3-2。
  3. 选层：点击任一楼层按钮（如 F5），进入该楼层钻取视图（见 3.6）。
  4. 取消选中：再次点击已选中的楼栋按钮，返回全院区全景，楼层列表收起。

图 3-2　选中 4 号楼后：顶部楼栋高亮，左侧出现楼层列表（F1–FN）

注意：楼栋按钮上的楼层数（如 12F）与楼层列表的层数均来自后台「楼栋管理」中配置的层数。若某楼栋显示 0F 或楼层列表为空，请到后台「楼栋管理」补录该楼层数（见 5.1 与第 10 章 FAQ-Q1）。

3.4 七大子系统数据卡片

图1 主驾驶舱左右两列即为 S1–S7 实时数据卡片：每张卡片显示子系统名称、核心指标（如设备总数、在线率、告警数、累计能耗）与迷你趋势图。卡片右上角为下钻入口，点击进入对应子系统驾驶舱屏。选中楼栋后，卡片数据自动切换为「该楼栋 × 该子系统」口径。

第 5 章 楼栋与三维场景配置

5.1 楼栋管理

「楼栋管理」（图 5-1）是全院楼栋台账的权威数据源，大屏楼栋导航、楼层列表、建筑面积表（图7）均取自本页数据。

图 5-1　楼栋管理：楼栋列表（层数、建筑面积、状态、操作）

查看楼栋列表：页签「楼栋列表」以表格展示序号、楼栋编码、楼栋名称、层数、建筑面积（m²）、启用状态，每行提供「编辑 / 删除」操作。

新增楼栋：点击右上角「+ 新增楼栋」，填写楼栋编码（如 B11）、名称、层数、建筑面积，保存后立即生效。

编辑楼栋：点击目标行「编辑」，可修改名称、层数、面积等字段。修改层数并保存后，大屏顶部楼栋导航的「NF」角标与该楼楼层列表将同步更新。

楼层配置：切换到「楼层配置」页签，可为每栋楼维护楼层明细（楼层序号、标签等），供楼层标签与大屏楼层钻取使用。

删除楼栋：点击「删除」并二次确认。删除会影响大屏楼栋导航，请谨慎操作。

5.2 楼栋子系统配置

「楼栋子系统配置」（图 5-2）控制每栋楼启用哪些子系统、以及子系统在大屏上的显示名称。

图 5-2　楼栋子系统配置：左侧选楼栋，右侧启停七大子系统

操作步骤：

  1. 在左侧「楼栋选择」列表点击目标楼栋；
  2. 顶部下拉框确认当前楼栋（如「120 急救中心 (6F / 12000m²)」）；
  3. 如需重命名楼栋，在「楼栋名称」输入框修改后点击「保存」；
  4. 在子系统列表中，通过每行的开关「启用 / 停用」该子系统；在名称输入框中可自定义子系统显示名（大屏顶部 tab 与卡片标题将跟随），点击该行「改名」保存；
  5. 完成后点击底部「保存配置」。页面底部显示「已启用 N / 7 个子系统」；「重置」按钮可放弃当前改动。

注意：停用某子系统后，大屏顶部对应 tab 与该楼栋的子系统卡片将隐藏。请确认业务上确不需要后再停用。

5.3 楼栋楼层标签

「楼栋楼层标签」（图 5-3）用于为每栋楼每一层自定义标签（如「F3 - 内科病区」）并绑定数据字段，大屏与三维视图即时联动。

图 5-3　楼栋楼层标签：楼层树 → 楼栋缩略图 → 标签编辑

操作步骤：

  1. 在左侧「楼层树」中按楼栋逐层展开，点击目标楼层节点；
  2. 中间「楼栋缩略图」联动显示该楼栋示意；
  3. 在右侧「标签编辑」区填写该层标签名称、绑定数据字段；
  4. 点击右上角「保存」，大屏 3D 楼层标签即时更新；「刷新」可重新加载最新数据。

5.4 楼栋显示 DIY

「楼栋显示 DIY」用于调整楼栋在三维场景中的显示效果（如楼栋位置锚点、显示开关）。管理员可在后台预览并拖动楼栋锚点，保存后大屏三维场景按新位置渲染。

5.5 场景模型上传与标记管理

场景模型上传：支持上传新的 GLB/GLTF 模型替换当前院区三维模型，上传成功后大屏重新加载即生效。

标记管理：维护三维场景中的标记点（如重点设备位置标记），可设置标记的位置、类型与关联对象，在大屏 3D 场景中随视角展示。

第 6 章 设备与告警管理

6.1 设备管理

「设备管理」（图 6-1）维护全院设备台账，支持按楼栋、子系统、设备类型筛选。

图 6-1　设备管理：设备台账列表与筛选

常用操作：

  1. 查询：顶部筛选条件（楼栋 / 子系统 / 关键字）组合查询，或直接搜索设备名称/编号；
  2. 新增设备：点击「新增」，填写设备名称、类型、所属楼栋与楼层、关联子系统等，保存后设备同步出现在大屏对应楼层钻取清单中；
  3. 编辑 / 删除：对既有设备修改参数或下线删除；
  4. 查看详情：点击设备行进入详情，可查看实时状态与历史曲线。

6.2 告警管理

「告警管理」（图 6-2）集中处理全院告警：近 7 日告警趋势、告警中心列表、实时告警与工单联动。

图 6-2　告警管理：告警趋势、告警中心与处理

常用操作：

  1. 按级别（紧急/重要/一般）与状态（未处理/已处理）筛选告警；
  2. 点击告警行查看详情（对象、时间、原因、前后值）；
  3. 执行「确认 / 处理 / 关闭」并填写处理意见；重要告警可一键生成工单进入处理流程；
  4. 在「异常配置」中维护告警阈值与规则，保存后新告警按新规则触发。

6.3 设备控制

「设备控制」页用于对可控设备（空调机组、水泵、照明回路等）下发远程指令：选择目标设备 → 选择控制动作（启停、设定值）→ 确认执行。所有控制指令均写入操作日志与审查追踪，可在第 9 章对应页面追溯。

警告：远程控制直接作用于现场设备。执行启停/设定类操作前，请再次核对设备编号与目标值，避免误操作。

6.4 历史数据

「历史数据」页支持按点位、时间范围查询历史采样数据，并可导出。查询结果以表格 + 趋势曲线呈现，用于能耗分析与故障回溯。

「操作日志」记录后台所有写操作（新增/修改/删除/控制指令），支持按操作人、模块、时间范围检索，用于日常运维追溯。

9.4 审查追踪（审计合规）

「审查追踪」（图 9-2）是面向 GMP/审计合规的防篡改审计模块，核心特性：

  • 哈希链防篡改：审计记录逐条计算哈希并链接前条（prev_hash/hash），任何篡改都会破坏链条且可被校验发现；页面顶部显示「审计合规 · 历史记录条数」与每条记录的「已签名」完整性状态；
  • NTP 时间同步：顶部显示「时间源 NTP 已同步」，保证审计时间戳可信；
  • 周期复核：显示上次复核时间与复核间隔（默认 30 天，可配置）；
  • 记录只增不改：审计记录为 append-only，任何账号（含管理员）均不能修改或删除历史记录；
  • 导出：支持「导出 CSV（本页）」「服务端导出 CSV」「服务端导出 JSON」与打印；导出文件包含完整哈希链字段，导出动作本身也会作为一条审计记录入链。

图 9-2　审查追踪：筛选条件、哈希链完整性标识与多格式导出

查询与导出步骤：

  1. 设置筛选条件：操作人（账号模糊）、模块、操作类型、关键字（对象/详情/原因）、起止时间；
  2. 点击「查询」刷新列表（支持分页浏览全部记录）；
  3. 点击需要的导出按钮获取文件；「导出 CSV（本页）」仅导出当前页，服务端导出导出符合条件的全量记录；
  4. 复核人员按周期点击「执行复核」核对链条完整性，复核记录同样入链。

第 10 章 常见问题（FAQ）

Q1：大屏上某楼栋显示 0F，或选中楼栋后楼层列表为空？

楼层数来自后台「楼栋管理」中该楼栋的层数配置。处理：进入「管理后台 → 楼栋管理」，点击该楼栋「编辑」，把层数改为正确值（如 6）保存；如需逐层信息，再在「楼层配置」页签补录。保存后刷新大屏即显示。

Q2：大屏三维场景一直显示「模型加载中」？

首次加载或网络较慢时属正常，请等待；若长时间不结束：检查服务器网络与带宽 → 强制刷新页面（Ctrl+F5）→ 在「管理后台 → 场景模型上传」确认模型文件有效，必要时重新上传。

Q3：页面提示接口请求失败 / 菜单空白？

多为后端服务未启动或网络不通。确认地址 http://117.21.178.39:5168 可达；若本机代理或防火墙拦截 5168 端口请放行；稍后刷新页面重试（应用会重新自动登录）。

Q4：忘记密码或需要新增账号？

由管理员在「管理后台 → 用户管理」重置密码或新增账号；普通用户请联系系统管理员处理。

Q5：审查追踪里的记录能不能修改或删除？

不能。审计记录采用 append-only 哈希链保护，任何账号（包括 admin）均无法修改或删除历史记录，这是合规要求的设计特性。如需留档请使用页面的导出功能。

Q6：大屏布局/样式改坏了想还原？

分别进入「大屏布局 DIY」与「大屏样式配置」，点击「恢复默认」即可还原出厂配置。

Q7：导出的文件在哪里？

浏览器下载目录。审查追踪、能耗报表等导出均为标准 CSV/JSON/Excel 文件，CSV 文件含 UTF-8 BOM，Excel 可直接打开不乱码。

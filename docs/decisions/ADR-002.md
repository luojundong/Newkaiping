# ADR-002: 图标库锁定 — lucide-vue-next（SVG）

- 状态：Accepted（2026-08-17）
- 决策者：高见远（首席架构师）

## Background
项目 P0 绝对规则：禁止 emoji 图标方案；Spec 必须锁定一套 SVG 图标库（由架构师选型）；技术栈选型必须包含锁定图标库的依赖。参考项目使用 `font-awesome@4.7.0`（图标字体，非纯 SVG，且与 lucide 混用风险）。需在全项目统一为单一 SVG 图标源，满足可维护性、Tree-shaking 与 P0 合规。

## Decision
锁定 **`lucide-vue-next`** 为全项目唯一图标源（SVG、MIT、Tree-shakeable、24px 描边风格一致，Vue3 友好，图标丰富度适配能源/电力/设备专业场景）。

- 全项目代码（大屏/后台）图标统一从 `lucide-vue-next` 引入，不再使用 Font Awesome、@element-plus/icons-vue 或任何 emoji。
- `@element-plus/icons-vue` 仅允许在 Element Plus 组件内部随组件使用（属 UI 库自带），不另行作为业务图标源，避免混用。
- `subsystems.icon` / `menus.icon` 字段存储 lucide-vue-next 图标名（如 `Gauge`、`Cpu`、`Wind`、`Lightbulb`、`Zap`、`Droplet`、`TrendingUp`）。
- `package.json` 依赖必须包含 `lucide-vue-next`（版本锚定 ^0.468.0）。

## Consequences
正面：
- 满足 P0 规则（SVG、单一源、依赖锁定）。
- 一致视觉语言、按需打包、体积小。
- 与 Vue3 SFC 用法契合（`<Component :is="icon" />`）。

负面：
- 需将参考项目现有 `fa-*` 类名机械迁移为 lucide 等价图标（一次性，低风险）。

## Alternatives
- 保留 Font Awesome（图标字体）：非纯 SVG、与 P0「锁定 SVG 图标库」冲突，拒绝。
- @element-plus/icons-vue 作主源：图标集偏 UI 控件、业务语义不足，且混用风险，未采用（仅允许在 Element Plus 组件内部随组件使用）。
